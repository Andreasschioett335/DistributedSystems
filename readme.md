HOW TO RUN APLICATION:

1. Open 3 terminals and run "go run ./node x" where the x is a number between 1 and 3 which decides the localhost port.
2. These should be opened within 10 seconds of each other, so all is live before they start sending requests. 
3. All 3 terminals need to be running for the program to work.
3. Open the log files to see the individual node's output.
